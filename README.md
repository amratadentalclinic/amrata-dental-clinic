# Dr. Amrata Dental Clinic — Website

Official website for **Dr. Amrata Dental Clinic**, a trusted dental practice in Jagatpura, Jaipur, Rajasthan.

🌐 **Live**: [www.amratadentalclinic.com](https://www.amratadentalclinic.com)

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 (single-page) |
| Styling | Tailwind CSS (CDN) + Custom CSS |
| JavaScript | Vanilla JS |
| Icons | Lucide Icons (CDN) |
| Fonts | Google Fonts (Inter + Playfair Display) |
| Forms | Web3Forms |
| Maps | Google Maps Embed (free) |
| Hosting | Vercel |

## Features

- ✅ Responsive design (mobile-first)
- ✅ Contact form with Web3Forms integration
- ✅ Click-to-call and WhatsApp deep links
- ✅ Google Maps embed
- ✅ Image lightbox with keyboard navigation
- ✅ Smooth scroll animations
- ✅ SEO optimized (JSON-LD, OG tags, sitemap)
- ✅ Working hours with today-highlight

## Project Structure

```
├── index.html              # Main page
├── assets/
│   ├── css/style.css       # Custom styles
│   └── js/main.js          # Interactivity
├── images/                 # Clinic & doctor photos
├── vercel.json             # Deployment config
├── robots.txt              # SEO
├── sitemap.xml             # SEO
├── site.webmanifest        # PWA manifest
└── favicon.*               # Favicons
```
